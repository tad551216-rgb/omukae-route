# おむかえルート帖 LINE版

放課後等デイサービスの送迎ルートづくりに、**LINEでの自動連絡**を足したものです。
[おむかえルート帖](https://github.com/tad551216-rgb/omukae-route) から分かれた、独立したアプリです。

▶ https://tad551216-rgb.github.io/omukae-route-line/

---

## できること

本体と同じ機能に加えて、

- 確定したルートを、**車ごとに担当ドライバーのLINEへ自動で送る**
- ドライバーが本文末尾のリンクを押すと、**管理者へ「確認完了」が届く**
- 送信前に本文をそのまま確認・修正できる

送るのは、これまで手でコピーしていた連絡文と同じものです。

---

## 本体との関係

| | おむかえルート帖 | おむかえルート帖 LINE版 |
|---|---|---|
| データの保存先 | `omukae-techo-v1` | `omukae-line-v1` |
| 学校データベース | 自前（`data/`） | 本体のものを参照 |
| LINE連絡 | なし | あり |

**データは完全に別々です。** 同時に使っても混ざりません。
本体から移すときは、本体の「書き出してコピー」→ こちらの「読み込む」で引き継げます。

学校データベース（全国約3万校）は本体の `data/` を参照しているため、
**本体のリポジトリは残しておいてください。**

---

## LINE連絡を使うには

中継（Google Apps Script）をご自身で1つ用意します。
手順は `docs/line-relay-setup.md` をご覧ください。おおよそ30分です。

中継を用意しなければ、これまでどおり手でコピーして送る使い方のままです。

---

## 個人情報のあつかい

- データはすべて端末のブラウザ内だけに保存されます
- LINEへ送られるのは、**確定したルートの連絡文だけ**です（ご自身の中継を経由します）
- 児童は**ニックネーム**で登録します。実名は入れないでください
- LINEのトーク履歴はLINE側に残ります。本文に実名を入れない運用を続けてください
- お送りサインは、これまでどおりLINEには載せないでください

## つかっているもの

単一ファイルのPWAです。フレームワークもビルドも使っていません。
学校データの出典は文部科学省「学校コード」、座標は国土地理院の住所検索です。
